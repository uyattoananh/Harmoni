Gaming

The minibar and locket work with borderless windowed and windowed games. For fullscreen exclusive games, the overlay cannot be displayed on top. Position the minibar where you want it before launching the game. To reposition, Alt+Tab out of the game, move the minibar, then switch back.

Local Media Detection

Detects music playing in Spotify, YouTube Music, and other apps. Progress tracking may be limited for browser-based players (Chrome reports approximate position only). Desktop apps like Spotify provide full tracking.

Spotify

Spotify API integration requires the app owner to have Spotify Premium. Playlist browsing, search, and playback control are available through the Spotify Web API with OAuth login.

Platform Support

Windows — Full support via GSMTC
macOS — Spotify and Apple Music via AppleScript
Linux — Any MPRIS2 player via playerctl
